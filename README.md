# Maruti Infrastructure Automation - Technical Deep Dive

A professional single-page scroll web application showcasing how AI-powered tag-based resource discovery enables intelligent infrastructure automation.

## Features

- **Modern Design**: Professional dark theme with gradient accents
- **Smooth Scrolling**: Continuous flow layout for optimal reading experience
- **Syntax Highlighting**: Clear, color-coded Terraform code examples
- **Core Logic Explanation**: Detailed breakdown of tag-based resource discovery
- **Execution Order**: Dedicated section highlighting dependency management

## Getting Started

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
```

This creates a static export in the `out/` directory.

## Technology Stack

- **Next.js 14**: React framework with App Router
- **TypeScript**: Type-safe development
- **Tailwind CSS**: Utility-first styling
- **Static Export**: Can be deployed anywhere

## Key Concepts Explained

1. **LLM-Generated Tags**: How AI creates semantic resource identifiers
2. **Tag Application**: How tags are applied to AWS resources via Terraform
3. **Tag-Based Discovery**: How dependent resources find each other dynamically
4. **Execution Order**: Why dependency-aware sequencing is critical

## Color Scheme

- **Primary**: Blue tones (#0ea5e9 to #0369a1)
- **Background**: Dark slate (#0f1419 to #1a2332)
- **Accents**: Emerald, Purple, Orange for different concepts
- **Code Blocks**: Dark with syntax highlighting
